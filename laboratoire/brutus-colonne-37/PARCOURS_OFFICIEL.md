# Parcours officiel — Brutus Colonne 37

Statut : parcours de référence du prototype, version Z-STAMP.

## Les 4 organes maîtres

1. Cortex Brutus / Pinéale — contient la référence à la Constante Brutus et scelle le Z.
2. Papillon — routage, rareté et routes 144.
3. Bibliothèque 37 — index canonique ultra-rapide.
4. Reine / Fourmis — tri, fusion, recyclage et entretien.

Le Cortex Brutus est un organe maître : il ne devient pas une 34e vertèbre. La machine reste donc 33 vertèbres + 4 organes = 37 postes.

## Porte d’entrée verrouillée

Le début du parcours est désormais :

**C1 Entrée → Cortex Brutus / Pinéale → Z-STAMP → C2 Empreinte → C3 Bibliothèque**

Règles :

- C1 normalise explicitement la matière.
- Le Cortex intervient avant toute empreinte technique C2.
- Le Z-ID est canonique pour la matière : deux chemins différents vers la même matière conservent le même Z-ID.
- La provenance, le parent Z et le chemin sont conservés séparément dans la lignée Z.
- C2 calcule l’empreinte technique de la matière déjà estampée Z.
- La Constante Brutus est une référence du sceau; elle n’est jamais appliquée numériquement sans déclaration explicite.
