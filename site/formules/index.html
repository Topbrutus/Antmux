GSP-001

Brutus Offset Test

RELATION EXACTE SUR CHIFFRE
t_a = (a + 1) mod 10 Δ_B(a) = 1 + min(t_a, 10 - t_a)

Cette relation travaille sur le dernier chiffre décimal. Elle décale d’abord le chiffre de +1 modulo 10, puis mesure la distance minimale sur le cycle décimal. Le résultat est donc déterministe pour chaque chiffre d’entrée.
